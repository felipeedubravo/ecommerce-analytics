**E-Commerce Analytics: Estatística e Exploração de Dados**

Este projeto é uma análise estatística e exploratória detalhada de um conjunto de dados de E-commerce, desenvolvida em um Jupyter Notebook (`ecommerce_estatistica.ipynb`). O objetivo principal é extrair *insights* valiosos sobre o comportamento de vendas, padrões de clientes e métricas de desempenho utilizando técnicas de estatística descritiva e visualização de dados.

**Tecnologias Utilizadas**

* **Python:** Linguagem principal para análise.
* **Pandas & NumPy:** Manipulação, limpeza e cálculos estatísticos.
* **Matplotlib & Seaborn:** Criação de visualizações gráficas e relatórios visuais.
* **Jupyter Notebook:** Ambiente de desenvolvimento interativo.

**Funcionalidades**

* Limpeza e tratamento de dados brutos (identificação de nulos, duplicatas e *outliers*).
* Geração de estatísticas descritivas (média, mediana, desvio padrão, quartis).
* Visualização de distribuições, tendências temporais e correlações entre variáveis comerciais.
* Segmentação de dados com base em métricas de negócio (ex: categorias de produtos, faturamento por região).

**O que os usuários podem fazer**

* Executar o notebook passo a passo para acompanhar o raciocínio analítico.
* Alterar parâmetros das funções de plotagem para visualizar diferentes variáveis do dataset.
* Replicar a lógica de tratamento de dados e estatística em seus próprios conjuntos de dados comerciais.

**Atalhos de Teclado (Jupyter Notebook)**
Para facilitar a navegação e execução do projeto, utilize os atalhos padrão do Jupyter:

* `Shift + Enter`: Executa a célula atual e avança para a próxima.
* `Ctrl + Enter`: Executa a célula atual e permanece nela.
* `A`: Insere uma nova célula acima (Modo de Comando).
* `B`: Insere uma nova célula abaixo (Modo de Comando).
* `M`: Transforma a célula em Markdown (Modo de Comando).
* `Y`: Transforma a célula em Código (Modo de Comando).

**Processo de Desenvolvimento**
O projeto foi construído seguindo um fluxo clássico de Ciência de Dados:

1. **Ingestão de Dados:** Importação do arquivo de e-commerce e inspeção inicial da estrutura (tipos de dados e volumes).
2. **Data Cleaning:** Tratamento de inconsistências que poderiam enviesar os resultados estatísticos.
3. **Análise Exploratória de Dados (EDA):** Aplicação de testes estatísticos e cruzamento de variáveis para responder perguntas de negócio.
4. **Storytelling Visual:** Construção de gráficos que traduzem os números em tendências claras.

**O que aprendi**

* Aprofundamento em bibliotecas essenciais de Python (Nível Intermediário) para lidar com bases de dados do mundo real.
* A importância de identificar e tratar *outliers* para não distorcer a média de vendas ou ticket médio.
* Como traduzir conceitos estatísticos abstratos em *insights* de negócio práticos e visuais.

**Como poderia ser aprimorado (Trabalhos Futuros)**

* Implementação de modelos preditivos (Machine Learning) para projetar vendas futuras.
* Exportação dos dados limpos para a criação de um Dashboard interativo em Power BI.
* Análise de Cohort para entender a retenção de clientes ao longo do tempo.
